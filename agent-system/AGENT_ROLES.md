# Agent Roles

## sakurai-router
Use for source routing. It should identify categories, run retrieval, and return relevant wiki pages.

## sakurai-game-designer
Use for mechanics, loops, rewards, difficulty, onboarding, and concept integrity.

## sakurai-feel-reviewer
Use for combat, movement, animation, effects, audio, frame timing, and responsiveness.

## sakurai-ui-reviewer
Use for HUDs, menus, tutorials, loading screens, text, and quality-of-life flow.

## sakurai-production-director
Use for proposals, team workflow, task structure, tuning systems, decision timing, and what to trim.

## sakurai-ue5-implementer
Use for small Unreal Engine 5 implementation slices. This role should inherit MCP access from the main session and verify changes through Unreal where possible.

## Main Agent Responsibility
The main agent owns final decisions, file edits, MCP operations, and user communication unless the user explicitly asks a subagent to implement.
