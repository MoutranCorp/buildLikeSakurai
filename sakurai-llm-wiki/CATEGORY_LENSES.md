# Category Lenses

Use this file to decide which part of the playlist should dominate an answer.

## Channel / Meta
- Use for Sakurai's intent, channel context, and higher-level framing about why the body of work exists.

## Design Specifics
- Use for tactile mechanics, movement behavior, collision nuance, input interpretation, and the micro-rules that decide whether play feels sharp or mushy.

## Game Concepts
- Use for case studies from Sakurai's shipped projects and for examples of how a concept evolves into a finished game identity.

## Planning & Game Design
- Use for structure, pacing, tutorials, feature framing, market fit, and the broad decisions that shape the playable whole.

## Game Essence
- Use for the question "what is the real fun here?" This category is the core for loop design, reward thinking, and strategic meaning.

## Work Ethic
- Use for personal discipline, proposal habits, directorial standards, decision-making pace, and the mindset needed to actually finish strong work.

## Grab Bag
- Use for supporting context, industry commentary, history, and Sakurai's wider way of thinking when the answer needs color rather than one narrow rule.

## Graphics
- Use for visual readability, hierarchy, scale, collision emphasis, style consistency, and how art choices affect function.

## Animation
- Use for anticipation, follow-through, posing, information loss, impact, and how motion communicates gameplay state.

## Effects
- Use for flashes, smoke, hit marks, particle timing, screen shake, and other tools that sell action and clarify consequences.

## UI
- Use for HUDs, menus, text, quality-of-life features, onboarding surfaces, and all information the player must parse directly.

## Programming & Tech
- Use for tunability, file organization, debug support, task tracking, and production systems that make iteration sustainable.

## Audio
- Use for weight, tempo, ambience, mix balance, feedback sounds, and how audio shapes both fiction and mechanics.

## Team Management
- Use for communication, organizational structure, balancing human cost, role clarity, and directorial tradeoffs inside a team.

## Marketing
- Use for public framing, accurate expectation-setting, demos, reveal strategy, and the relationship between the game and the market story around it.

## Planning & Design
- Treat this as an edge-case overlap bucket. Use it when a video bridges concept-level planning and specific design execution in one place.
